# Space telemetry

Read-only Guest Kotlin example for Compukters: Cosmonautics on Minecraft 1.21.1.
Open this directory in the IDE, resolve dependencies against a server with the addon and compile/deploy.
On a surface world it reports the planet transition altitude. On a loaded construction in Deep Space it reports
instance orbital elements and matching planet apsis altitudes. It does not fly the ship or prove a safe orbit;
missing data produces an explicit message. Frames must match before combining observations.
